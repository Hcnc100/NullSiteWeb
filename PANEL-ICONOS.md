# Iconos del panel

Reutilizada la dependencia Font Awesome existente, sin instalar librerías nuevas.

- Iconos en las pestañas, cierre de sesión y acciones de edición de proyectos y perfil.
- Botón compacto de papelera para quitar capturas, con nombre accesible que incluye el número y ayuda al pasar el cursor.
- Ayuda extensa de galería plegada para reducir texto visible.
- Se mantienen etiquetas en navegación y acciones principales, además de avisos de guardado/borrado: los iconos no sustituyen información importante.
- Iconos decorativos ocultos a tecnologías de asistencia para evitar lectura duplicada.

Validación: 23 pruebas dirigidas correctas y build correcto antes del último ajuste de papelera compacta. No se ha realizado revisión visual interactiva ni despliegue.

## Key Learnings:
1. El usuario prefiere aprovechar Font Awesome existente para reducir el ruido textual del panel.
2. Las acciones compactas de icono necesitan nombre accesible, área táctil suficiente y ayuda contextual.
